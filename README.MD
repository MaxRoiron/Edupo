## Installation & Lancement

Une fois le projet cloné sur votre machine :

### 1. Prérequis
Assurez-vous d'avoir **Node.js** (version 18 ou supérieure) installé.

### 2. Installation des dépendances
Rendez-vous dans le dossier du frontend et installez les paquets nécessaires :

```bash
cd front
npm install
```

### 3. Lancer le projet
Démarrez le serveur de développement :

```bash
npm run dev
```

Le site sera accessible à l'adresse : [http://localhost:3000](http://localhost:3000)

## 🛠️ Stack Technique
- **Framework** : Next.js 15 (App Router)
- **Langage** : TypeScript
- **Styles** : CSS Modules / Styled JSX
